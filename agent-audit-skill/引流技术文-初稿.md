## 1｜开场：你只看到结果，看不到它"为什么这么做"

把 RAG + LLM + 工具链交给 Agent 自动跑任务，体验很爽——直到出事那天。

它悄悄调用了一个**不该碰的工具**（越权），
对着一个**没证据的高风险结论**拍胸脯（依据缺失），
引用了**一段来路不明、无法溯源**的内容，
甚至前后两步**自相矛盾、状态漂移**——而你，事后说不清每一步它到底为什么这么做。

问题不在模型不够聪明，而在：**Agent 的"自动驾驶"缺一块黑匣子。**

飞机有黑匣子，Agent 也应当有。这就是我开源 **`agent-audit-mcp`** 的初衷——给 AI Agent 的每一步决策，装一个**可枚举、可审计、可回溯**的"认知黑匣子"。

## 2｜难点：Agent 的决策为什么难审计

先摆四个真实的风险，你大概率遇到过：

1. **越权调用**：碰了权限之外的工具或数据；
2. **高风险结论缺证据**：全仓、删除、对外承诺，却拿不出依据；
3. **引用不可溯源**：结论对，但说不清来源；
4. **状态跳变逃逸**：这一步还保守、下一步突然激进，前后决策漂移。

难点在于：**决策是"过程"，而日志只是"流水"**。要让过程可审计，得先把"一步决策"变成一个**可枚举、可比较的状态**——这正是 `agent-audit-mcp` 的核心思路。

## 3｜核心思路：把一步决策编码成九维状态

我们从 **9 个观察维度** 刻画一步决策：

> 结构 · 功能 · 关系 · 属性 · 时间 · 情境 · 因果 · 价值 · 演化

每个维度取 **三态**：

- `⊕`（+1）偏强/超常
- `0`（0）中和
- `⊖`（−1）偏弱/不足

于是一步决策 = 一个**九维三态向量**，例如 `0⊖0⊖000⊖0`。
9 位三态一共 **3⁹ = 19683** 个状态，中心态（全 0）的枚举键 `idx = 9841`。

这一步是东方易理的三态思维（⊖/0/⊕）× 现代 AI 工程的结合：**可枚举**（每个决策有唯一地址）、**可比较**（两个状态算 Hamming 距离）、**可复现**（同样输入必得同样状态）。

## 4｜判定规则：透明、可复现、阈值可调

有了状态，审计就是几条清晰的规则：

| 触发 | 结论 | 处置 |
| --- | --- | --- |
| v6 情境 · **越权** | 🔴 **BLOCK** | 阻断执行，回退并补授权 |
| v7 因果 · **依据缺失** 或 v8 价值 · **高风险** | 🟠 **ALERT** | 停止自动执行，转合规复核 |
| 相邻步 Hamming 距离 **> 4**（状态跳变） | 🟡 **WATCH** | 人工复核跳变点 |
| 以上皆无 | 🟢 **OK** | 继续执行 |

阈值（如"高风险""依据缺失"的边界）**全部可用环境变量覆盖**，接真实日志后按需校准——规则对你是透明的，不是黑箱。

## 5｜看真实效果（本地引擎真跑，非示意）

用四个预设场景跑一遍：

- 🟢 **正常投顾建议 → OK**：`步1 0⊖0000000`，`步2 0⊕0⊕00⊕⊕0`，无红线、无跳变；
- 🟠 **高风险全仓建议 → ALERT**：`步1 0⊖0⊖000⊖0` 命中 v8 高风险；`步2 ⊖⊕⊖⊖⊕0⊖⊖⊕` 命中 v7 依据缺失 + v8 高风险；
- 🔴 **越权查询与荐股 → BLOCK**：`步1 0⊖⊖⊖0⊖⊖00` 命中 v6 越权 + v7 依据缺失；
- 🟡 **状态跳变逃逸 → WATCH**：从 `0⊖0000000` 一步跳到 `⊕⊕⊕⊕⊕00⊕⊕`，Hamming 距离 **7**，触发人工复核。

每一步都给出九维向量、`idx`、平衡值 `bal`、命中的红线和处置建议——这就是一块能读的"黑匣子"。

## 6｜架构与接入（三分钟跑起来）

```
Agent 编排层 ──┬── 日志钩子 ──▶ signals(信号)
               └── 九维审计 ──▶ 九维状态 → 轨迹审计 → OK/WATCH/ALERT/BLOCK 报告
```

它是一个标准 **MCP Server**，接入后 WorkBuddy 对话里直接说"审计这一步决策…"即可调用。三个工具：

- `audit_agent_step`：审计单步 → 九维状态编码 + 红线
- `audit_agent_session`：审计整段会话轨迹 → 四档总结论 + 处置建议
- `encode_state`：九维向量 ⇄ 枚举键/平衡值，可算 Hamming 距离

快速开始：

```bash
cd agent-audit-mcp
python -m pip install -e .     # 需 Python≥3.10，MCP SDK≥2.0
python ../agent-audit-skill/install.py   # 一键注册为 WorkBuddy 连接器
```

一次调用长这样：

```jsonc
// 入参（audit_agent_step）
{ "signals": { "tool_calls": 2, "intent": "produce",
               "evidence": 4, "citations": 3, "traceable": true,
               "risk_hit": true } }

// 返回（节选）
{ "vector": [0,1,0,0,0,0,1,-1,0], "vector_str": "0⊕0000⊕⊖0",
  "idx": 12034, "bal": 2193, "flags": ["RED:v8高风险"],
  "semantic": "偏强/超常：步骤意图、决策依据链；偏弱/不足：风险等级" }
```

## 7｜为什么值得关注

- **纯本地 / 零外部依赖**：编码引擎是纯数学，审计全程本地跑，决策轨迹不出你的机器——既是卖点，也是合规点；
- **确定性可复现**：同样输入必得同样结论，能直接写进合规审计报告；
- **标准 MCP**：三个工具开箱即用，可嵌入任何 Agent 流水线做"日志钩子"。

对企业，它把 Agent 治理从"玄学"变成了一台**可审计的状态机**。

## 8｜结尾

Agent 会越来越自主，但"自主"不等于"放任"。给每一步决策一个可枚举、可回溯的认知坐标，是让 AI 安全落地的地基之一。
