## 三、变现分层（从免费到付费）

| 层级 | 内容 | 定价思路 |
| --- | --- | --- |
| **L0 开源免费** | 核心引擎 + 3 工具 + stdio 连接器（当前版本） | 免费，引流 + 建立心智 |
| **L1 专业版** | 阈值面板、审计报表导出（JSON/PDF）、批量会话审计 CLI | 一次性授权 或 订阅 |
| **L2 企业版** | 私有化部署、对接现有日志系统、权限/审批流集成、SLA | 项目制 + 年维护 |
| **L3 顾问/内训** | 把九维认知审计方法论带入企业 AI 治理 | 按天/按项目 |

> 定价锚点：让 L1 价格显著低于"一次 AI 决策事故的合规成本"，把账算给企业看。

## 四、引流打法（组合拳）

1. **技术文引流**：按 `引流技术文提纲.md` 发公众号/知乎/掘金，文末挂 GitHub + 市场入口。
2. **短视频/图文**：30 秒演示"一个越权场景如何被 BLOCK"，视觉冲击强。
3. **SEO 关键词**：AI Agent 审计、Agent 合规、MCP server、九维认知空间、Agent 越权检测。
4. **借势**：每次大模型/Agent 安全热点事件，跟进一篇"用九维认知空间审计这类问题"。

## 五、风险与合规

- **不碰投资建议**：工具定位是"开发者审计工具"，README 已含免责声明。
- **数据边界**：审计全程本地/可控，宣传时强调"决策轨迹不出机器"，这是卖点也是合规点。
- **阈值诚实**：默认阈值标注为"示例值，需按真实日志校准"，避免过度承诺。
- **命名规范**：对外统一 `agent-audit-mcp`，版本号遵循语义化（当前 1.0.0）。
